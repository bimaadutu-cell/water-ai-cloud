# V50 — HTML-only games + Termux keyboard + Block Blast + Ludo

## Changes
1. **Chess & TTT**: hanya kirim **media HTML** (tidak ada PNG)
2. **Termux**: keyboard on-screen real-time + input bar di HTML
3. **`.blockblast` / `.blockblas`**: game susun blok warna-warni, clear baris/kolom, skor + combo
4. **`.ludo`**: Ludo + ular tangga, VS AI / teman lokal / undang online (`.ludo undang 08xxx`)

## Commands

- `.termux` — terminal + keyboard
- `.blockblast` — Block Blast
- `.ludo` / `.ludo undang 08…` / `.ludo terima`
